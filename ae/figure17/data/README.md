# Figure 17 data

`figure17_energy_breakdown.csv` is generated by the shared
`../../energy_model.py` from the fixed Recall@10 execution-trace table and
the repository's final YAMLs.

Every dataset is normalized independently to its `NMP-Base` total energy:

```text
normalized compute = method compute energy / NMP-Base total energy
normalized memory  = method memory energy  / NMP-Base total energy
normalized total   = normalized compute + normalized memory
```

`NMP-Base-ET` and MFNNS intentionally have identical memory components
because Base-ET is derived from the `mfnns` execution trace. Their
total-energy difference is entirely compute energy.
